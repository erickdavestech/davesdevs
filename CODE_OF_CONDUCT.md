# Código de conducta

DavesDevs busca una colaboración respetuosa, profesional y segura.

## Comportamiento esperado

- Comunicarse con claridad y buena fe.
- Criticar decisiones y código, no personas.
- Respetar experiencia, identidad, contexto y tiempo de los demás.
- Proteger información privada y material de clientes.
- Reconocer errores y corregirlos sin ocultar impacto.

## Comportamiento no aceptado

- Acoso, discriminación, amenazas o ataques personales.
- Publicación de información privada o credenciales.
- Contenido sexual, violento o deliberadamente humillante.
- Spam, manipulación de métricas o promociones irrelevantes.
- Uso del proyecto para infringir derechos de terceros.

## Aplicación

Las incidencias de conducta no deben contener datos sensibles. El mantenedor puede editar, cerrar o rechazar contribuciones y restringir participación cuando sea necesario para proteger el proyecto y a sus participantes.
